
# Channel Mapping

| Channel | Input | Function |
|---|---|---|
| CH1 | Left Y | Throttle / Flapping amplitude |
| CH2 | Right X | Aileron / Steering |
| CH3 | Left X | Auxiliary |
| CH4 | Right Y | Auxiliary |
| CH5 | Momentary button | ARM / DISARM |
| CH6-CH12 | Reserved | Expansion |

## Analog Channels

Minimum: 1000
Center: 1500
Maximum: 2000

## CH5

1000 = DISARM
2000 = ARM

Short press toggles the controller ARM state.

Receiver must independently validate ARM requests.
